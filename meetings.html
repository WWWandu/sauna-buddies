Adding a new meeting

Each meeting lives as its own page inside the /meetings folder, named by date (for example meetings/2026-09-11.html). To add a new one: copy the most recent meeting page as a template, update its content, then add one new row to this archive page linking to it. No other page needs to change — see the project README.md for the full walkthrough.
